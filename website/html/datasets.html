MSchlo578 Dataset

578 Samples

Training dataset containing experimentally verified chloroplast proteins.

Key Features:
  • Five major locations: Envelope, Stroma, Thylakoid lumen, Thylakoid membrane, Plastoglobule
  • Sequence similarity < 40%
  • High-quality annotations

Novel Dataset

122 Samples

Independent test set for model evaluation.

Dataset Overview:
  • 113 single-location proteins
  • 9 dual-location proteins
  • New proteins (2013-2015)
  • No overlap with training data

SLP15267 Dataset

15,267 Samples

Extended dataset from UniProtKB/Swiss-Prot (Jan 2024).

Distribution:
  • Chloroplast: 10,207
  • Membrane: 4,129
  • Other locations: 931
